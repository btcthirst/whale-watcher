# Whale Watcher 🐋

*Read this in other languages: [English](README.md), [Українська](README.uk.md)*

Надійний Go-застосунок, розроблений для відстеження та надсилання сповіщень про великі транзакції ("китів") у блокчейні Solana в режимі реального часу.

## Можливості

- **Моніторинг у реальному часі**: Використовує WebSocket-підписку Solana `logsSubscribe` для миттєвого виявлення подій.
- **Покращене отримання даних**: Інтегровано з Helius API для швидкого та надійного отримання детальної інформації про транзакції.
- **Розумний рушій оцінювання**: Визначає вартість токенів, опитуючи ланцюжок провайдерів цін (Jupiter → DexScreener → GeckoTerminal) із вбудованим кешуванням для оптимальної продуктивності.
- **Налаштовувані пороги**: Легко конфігуруйте алерти на основі:
  - Мінімальної суми в SOL
  - Мінімального еквіваленту у USD
  - Мінімальної кількості токенів (для токенів із невідомою ціною)
- **Багатоканальні сповіщення**: Підтримує сповіщення в реальному часі через **Telegram** та **Webhooks**.
- **Збереження даних**: Використовує локальну базу даних **SQLite** для надійного збереження оброблених переказів та виявлених подій "китів".
- **Чиста архітектура**: Написано на Go з акцентом на модульність, можливість тестування та високу продуктивність.

## Вимоги

- [Go](https://golang.org/doc/install) версії 1.21 або вище
- Solana WebSocket endpoint (наприклад, QuickNode, Alchemy)
- [Helius API Key](https://dev.helius.xyz/)
- (Опціонально) Telegram Bot Token та Chat ID для сповіщень

## Встановлення

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/btcthirst/whale-watcher.git
   cd whale-watcher
   ```

2. Встановіть залежності:
   ```bash
   make deps
   ```

3. Налаштуйте змінні середовища. Скопіюйте файл `.env.example` у `.env`:
   ```bash
   cp .env.example .env
   ```
   
   Введіть ваші API-ключі та налаштуйте пороги у файлі `.env`:
   ```env
   TELEGRAM_BOT_TOKEN="ваш_токен_телеграм_бота"
   CHAT_ID=123456789
   HELIUS_API_KEY="ваш_ключ_helius_api"
   SOLANA_WS_URL="wss://ваш-solana-websocket-url"
   SOL_THRESHOLD=100
   USD_THRESHOLD=50000
   TOKEN_AMOUNT_THRESHOLD=1000000
   DB_PATH="whale.db"
   WEBHOOK_URL="https://ваш-webhook-endpoint.com"
   ```

## Використання

Ви можете запустити застосунок безпосередньо або зібрати виконуваний файл.

**Запуск безпосередньо:**
```bash
make run
```

**Збірка та виконання:**
```bash
make build
./bin/whale-watcher
```

## Розробка та Тестування

Проєкт включає `Makefile` для спрощення типових завдань:

- **Запуск тестів**: `make test`
- **Запуск лінтерів**: `make lint`
- **Форматування коду**: `make fmt`
- **Очищення артефактів збірки**: `make clean`

## Огляд архітектури

- **`cmd/watcher`**: Точка входу в застосунок.
- **`internal/infrastructure`**: Зовнішні інтеграції (Solana RPC, Helius API, Telegram, Webhooks).
- **`internal/application`**: Основна бізнес-логіка, рушій оцінювання (`pricer`), детектор "китів", дедуплікація даних та сервіс сповіщень.
- **`internal/storage/sqlite`**: Взаємодія з базою даних для збереження переказів та подій.
